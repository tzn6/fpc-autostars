# AutoStars — плагин автовыдачи Telegram Stars для FunPayCardinal

Плагин для [FunPayCardinal](https://github.com/sidor0912/FunPayCardinal), который **автоматически продаёт и выдаёт Telegram Stars**.

Когда покупатель оплачивает на FunPay лот со звёздами «по username», плагин сам:
1. ловит новый заказ;
2. определяет количество звёзд и Telegram-юзернейм получателя;
3. проверяет юзернейм через **Fragment**;
4. покупает звёзды на Fragment и оплачивает их **с твоего TON-кошелька** (W5 → tonapi.io);
5. сохраняет платёжную попытку до отправки, проверяет результат и исходящие платежи;
6. после подтверждения пишет покупателю «готово».

Бонусом — **авто-ответ на отзывы** покупателей.

Всё настраивается **прямо в Telegram-боте FPC**, без правки файлов.

> ⚠️ **Плагин работает с реальными деньгами (TON) и приватными данными** (сид-фраза кошелька, Fragment cookies).
> Используй **отдельный** кошелёк под автовыдачу и держи на нём только рабочий баланс. Автор ответственности не несёт.

## Установка

1. Скачай **`autostars.py`** и положи его в папку `plugins/` твоего FunPayCardinal.
2. Установи зависимость для работы с TON (в venv, где запускается FPC):
   ```bash
   /путь/к/FunPayCardinal/venv/bin/pip install pytoniq
   ```
   (`requests` уже идёт вместе с FPC).
3. **Активируй плагин** в ТГ-боте: `🔌 Плагины → AutoStars → Активировать`.
4. **Перезапусти FunPayCardinal** (хендлеры и страница настроек навешиваются при старте).
5. В логах должно появиться:
   ```
   [AUTOSTARS] Сервис запущен.
   [AUTOSTARS] Страница настроек в Telegram зарегистрирована.
   ```

## Обновление до 0.3.0

1. Дождись завершения текущих выдач и останови FPC. Если в 0.2.0 был таймаут или аварийное завершение, сначала проверь последние платежи кошелька: старая версия не сохраняла хеш до отправки.
2. Сохрани резервную копию `storage/plugins/autostars.json` и `storage/plugins/autostars_orders.json` в закрытом месте: в настройках есть секреты.
3. Замени `plugins/autostars.py` новым файлом и запусти FPC. Формат существующих настроек и заказов поддерживается; удалять `storage/` не нужно.
4. Открой настройки AutoStars один раз, чтобы сохранить чат продавца для уведомлений. Теперь он запоминается и после перезапуска.

### Что изменилось

- Сохранён фикс `seqno = max(tonapi_seqno, _min_seqno)`. Нижняя граница `seqno` восстанавливается из подтверждённых платежей при перезапуске и переподключении кошелька.
- Перед отправкой сохраняются подписанный BOC, хеш входящего сообщения, адрес кошелька, `seqno`, срок действия и ожидаемые платежи Fragment.
- Таймаут отправки или недоступный индексатор переводят заказ в ожидание результата. Новая покупка и автоматический возврат по неопределённой попытке не выполняются.
- Пока платёж действителен, через 30 секунд можно повторно отправить **те же подписанные байты**. Новые подпись, `seqno` и покупка Fragment при этом не создаются.
- После перезапуска проверяется прежний хеш. Подтверждение одного заказа в пакете не считается подтверждением остальных.
- Для успеха нужны успешное исполнение TON-транзакции и исходящее сообщение с ожидаемыми адресом, суммой и payload. Одного найденного хеша недостаточно.
- История и настройки записываются атомарно. При повреждении истории сервис останавливается, вместо запуска с пустым списком заказов.
- Исправлено завершение заказов после исчерпания попыток подготовки Fragment; продавцу приходят уведомления. Возврат считается выполненным после ответа FunPay; при неизвестном результате возврата автоматического повтора нет.

### Если результат платежа неизвестен

`TRANSFERRING` — плагин проверяет сохранённую транзакцию. Пока есть такая попытка, новые платежи приостановлены: их заказы и счётчик попыток сохраняются.

Если спустя две минуты после истечения срока платежа результата всё ещё нет, заказ получает `NEEDS_REVIEW`, а продавцу приходит уведомление с ID заказа и хешем сообщения. Плагин продолжает проверку: позднее подтверждение завершит заказ автоматически.

При `NEEDS_REVIEW` проверь историю TON-кошелька и результат заказа на Fragment. Если индексатор так и не даёт достоверного результата, потребуется ручной разбор. Снятие блокировки и повторная покупка автоматически не выполняются; отсутствие транзакции в ответе API само по себе не доказывает отсутствие платежа. Не удаляй журнал и не переводи спорный заказ в `READY`, пока не установишь результат прежней попытки.

Старые ошибки `TRANSFER_ERROR`/`TRANSACTION_TIMEOUT_ERROR` с оставшимися попытками и без сохранённого хеша также требуют проверки при обновлении: безопасно восстановить их результат из данных 0.2.0 невозможно.

## Настройка (в Telegram-боте)

`🔌 Плагины → AutoStars → ⚙️ Настройки`. Секретные значения скрыты и отображаются как «задано».

| Пункт | Что это |
|-------|---------|
| 🍪 Fragment cookies | Cookie авторизованного аккаунта на fragment.com |
| #️⃣ Fragment hash | Параметр `hash` из запросов к `fragment.com/api` |
| 🔐 Сид-фраза W5 | 24 слова кошелька TON W5, с которого оплачиваются звёзды |
| 🔑 tonapi токен | Токен [tonconsole.com](https://tonconsole.com) (необязательно, но убирает задержки) |
| 👤 Показывать отправителя | Показывать ли тебя как отправителя на Fragment |
| 📢 Реклама в комментарии | Пересобирать коммент к TON-транзакции (по умолчанию выкл — надёжнее) |
| 💸 Возврат при ошибке | Авто-возврат заказа на FunPay, если перевод не удался |
| ⏱ Интервал цикла | Как часто проверять готовые заказы (сек) |
| 🪫 Мин. баланс (TON) | Порог баланса: если ниже — автовыдача приостанавливается. 0 — выключено |
| 🔔 Уведомить о низком балансе | Присылать уведомление в Telegram при паузе/возобновлении |
| 📝 Ответ на отзыв | Авто-ответ на отзывы покупателей (вкл/выкл + текст) |
| 💬 Сообщения покупателю | Тексты ответов покупателю (успех/ошибка/неверный ник и т.д.) |

После заполнения ключей нажми **♻️ Переподключить** — бот ответит адресом кошелька и балансом.

## Автовыключение при низком балансе

Если баланс TON-кошелька падает ниже **«Мин. баланс»**, плагин:

1. Приостанавливает обработку переводов (новые заказы продолжают приниматься и ставятся в очередь).
2. Пишет в Telegram сообщение вида:
   > ⚠️ **AutoStars: низкий баланс!**
   > Текущий баланс: **0.3500 TON**
   > Порог: **1.0 TON**
   > Автовыдача **приостановлена**. Пополните кошелёк — плагин возобновит работу автоматически.
3. После пополнения кошелька плагин **сам снимает паузу** и шлёт уведомление о возобновлении.

Установи значение **0**, чтобы отключить функцию.

> Уведомления отправляются в чат, из которого ты последний раз открывал настройки AutoStars. Зайди в настройки хотя бы раз после установки или обновления; чат сохраняется в настройках и восстанавливается при запуске.

### Где взять Fragment cookies и hash
1. Зайди на **https://fragment.com**, авторизуйся через Telegram и подключи TON-кошелёк (тот же, чью сид-фразу вписал).
2. Открой `https://fragment.com/stars/buy`, нажми **F12 → Network**.
3. Введи в поле получателя любой `@username` — появится запрос `api?hash=...`.
4. Кликни по нему:
   - **hash** — значение после `?hash=` в Request URL;
   - **cookies** — строка `Cookie:` целиком из Request Headers.

> Cookies/hash со временем протухают — если переводы перестали идти с ошибкой Fragment, обнови их тем же способом.

### Где взять сид-фразу
Поставь **Tonkeeper** (создаёт кошелёк W5), заведи **отдельный** кошелёк под автовыдачу, пополни TON, экспортируй 24 слова: Настройки → Recovery phrase. Вставляй слова через пробел.

### Где взять токен tonapi
[tonconsole.com](https://tonconsole.com) → войти → tonapi → **API keys → Create** (тип **Unlimited**, для backend) → скопировать токен.

## Лоты на FunPay

Плагин ловит заказы из категории **Telegram → Звёзды**, тип **«По username»**. Покупатель указывает свой `@username` при оформлении или присылает в чат:
```
/stars свой_username
```
Можно с `@` и без — без разницы.

## Проверка изменений

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют таймаут после принятой отправки, повтор прежнего BOC, остановку до/после отправки, позднее подтверждение, частичный результат пакета, некорректный payload, повреждение/ошибку записи истории, возвраты и устаревший `seqno` после перезапуска. Сеть и подпись TON в тестах заменены имитацией; реальные Stars не покупаются. GitHub Actions запускает проверки на Python 3.10 и 3.12 при изменениях.
